# Stone OS Platform

Crie um dashboard operacional premium de gestão de Ordens de Serviço (OS), inspirado no design moderno da Stone Pagamentos, porém com estética glassmorphism e aparência SaaS enterprise de alto nível.

O sistema será utilizado em reuniões operacionais diárias para acompanhamento de SLA, vencimentos, criticidade e performance operacional.
